The colour calculation, on its own

This is a small test fixture. Your cards keep their own design. The only production file here is gradient-colour.js (or its minified version).

Prepare reads the visible photo crop and the pixels behind the text. Solve picks a colour that keeps white text readable. Change the target below: the prepared pixels are reused.

The small colour sample is an average of the bottom half of the visible crop. The contrast check uses detailed pixels behind every measured text line. It keeps the starting colour if it passes, or selects the lightest passing RGB shade towards black, with a 0.02 numerical allowance and a one-step pixel guard for tested browser paint differences.

The inline code below this page supplies the test layout and measurements. The engine supplies no card CSS, observers or fallback design. Automatic colour is the editor default; an optional starting-colour override still goes through the same check.
