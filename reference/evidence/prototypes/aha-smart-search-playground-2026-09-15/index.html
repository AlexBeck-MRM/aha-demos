Type to see quick results. Use up and down arrows to choose a suggestion, then Enter to accept it. Enter confirms a topic or asks a question here; only the View all results link opens the full results page. Tab moves to filters and result links. Escape hides suggestions first, then closes search.

Also check
  • The top-right icon and ⌘K / Ctrl+K open and close search. Escape restores focus.
  • Arrow keys + Enter accept a suggestion. Enter confirms topics and asks questions inside the panel. Tab reaches filters and links.
  • “View all results” carries the query, filter and answer into the results page. Browser Back returns to the panel.
  • Choose Mobile for a narrow layout. On a phone, test with the on-screen keyboard.
  • Recent searches last only until Reset or reload. No query is sent to a service.
